# Harsh Palkrutwar — Portfolio

A typography-led, responsive personal portfolio built with **Next.js App Router, React, TypeScript, Tailwind CSS 4, Motion, and Lucide icons**. No personal photo or hero artwork is used.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Before deployment

- In `app/layout.tsx`, replace `https://example.com` in `metadataBase` with the final portfolio domain.
- Check project links, especially repository naming and current project status.
- Deploy to Vercel by importing the GitHub repository; the default Next.js settings are detected automatically.

## Design notes

- Warm neutral canvas, ink typography, restrained slate-blue accent.
- Responsive project grid, leadership timeline, and contact area.
- Motion-based entrance reveals; reduced-motion preferences are respected.
- No image dependency in the hero or profile area.
